# 市原建設 ホームページ

大阪のエアコンクリーニング／ハウスクリーニング「市原建設」のコーポレートサイト（静的HTML・14ページ構成）です。
**お知らせ**と**料金表**は Google スプレッドシートを編集するだけで更新できます。

---

## ページ構成

ヘッダーのメニューは次のツリー構成です（インデントはドロップダウンの子メニュー）。

```
TOP
├── エアコンクリーニング … 家庭用エアコン／お掃除機能付き／業務用エアコン／室外機
├── ハウスクリーニング  … 浴室／キッチン／レンジフード／トイレ／洗面所
├── 空室清掃          … 1R／1LDK／2LDK／3LDK
├── 対応エリア
├── 施工事例
├── よくある質問
├── 法人のお客様
├── その他サービス
├── 採用情報
└── 会社概要
```

子メニューは**独立したページではなく、親ページの中の見出しへのリンク**です
（例：「家庭用エアコン」＝ `aircon.html#residential`）。
内容量に対してページを分けすぎると1ページあたりが薄くなり、検索でも不利になるため、
関連する内容は1ページにまとめ、ページ内ジャンプで行き来する形にしています。

| ファイル | ページ | 主な内容 |
|---|---|---|
| `index.html` | トップ | ヒーロー／お知らせ最新3件／選ばれる理由／サービス一覧／施工の様子／料金の目安 |
| `aircon.html` | エアコンクリーニング | 家庭用／お掃除機能付き／業務用／室外機の4区分＋対応できる症状・メーカー |
| `house.html` | ハウスクリーニング | 浴室／キッチン／レンジフード／トイレ／洗面所の5メニュー |
| `vacancy.html` | 空室清掃 | 1R／1LDK／2LDK／3LDK＋その他の間取り・戸建て |
| `area.html` | 対応エリア | 日本地図（対応エリアを色分け）／大阪市24区／大阪府内の主要市／即日対応・駐車場 |
| `works.html` | 施工事例 | 1件ごとにご相談内容・機器情報・写真4枚・お客様の感想 |

下の3ページ（サービス一覧・料金表・お知らせ）は、
**ヘッダーのメニューには入れず、ハンバーガーメニューとフッターからたどれる**ようにしています。
ヘッダーの項目数を増やしすぎると1行に収まらなくなるためです。
ヘッダーに出したい場合は「ヘッダー・フッターの直し方」の項をご覧ください。

各ページの下部には、他ページへの導線（OTHER PAGES）を置いています。

## Googleスプレッドシート連携の設定手順

設定は**1回だけ**で、全ページに反映されます（読み込み処理は `assets/main.js` 共通のため）。

### 1. スプレッドシートを用意する

1. Google ドライブで新しいスプレッドシートを作成します（例：`市原建設HPデータ`）。
2. シートタブの名前を **`お知らせ`** と **`料金表`** の2つにします。
3. `ファイル → インポート → アップロード` から `data/notices.csv` を選び、
   インポート場所を **「現在のシートを置換する」**（`お知らせ` シートを開いた状態で）にします。
4. 同じ手順で `data/prices.csv` を `料金表` シートに読み込みます。

> これで列の見出しが正しく入った状態になります。以降はこのシートを直接編集するだけです。

### 2. シートを読めるようにする（2つの方法）

#### 方法1：リンク共有だけで済ませる ← 現在この設定です

1. スプレッドシート右上の `共有` を押します
2. 「一般的なアクセス」を **「リンクを知っている全員」** にし、権限は **「閲覧者」** のまま
3. `assets/config.js` にシートのIDとタブ名を書きます（**設定済み**）

```js
sheets: {
  sheetId:      '1QkslWNs7Bhz_NB0q-8Pkf88eThuMKDSABV-ROuGp4yc',
  noticesSheet: 'お知らせ',
  pricesSheet:  '料金表',
```

IDはアドレス欄の `/d/` と `/edit` の間の文字列です。

- **利点**：手順が少なく、編集がほぼすぐ反映されます
- **注意**：タブ名を変えたら `config.js` も直してください

#### 方法2：ウェブに公開する（より確実）

1. `ファイル → 共有 → ウェブに公開` を開きます
2. 「リンク」タブで、公開対象に **`お知らせ`** シートを選択します
3. 形式のプルダウンで **「カンマ区切り形式（.csv）」** を選びます
4. `公開` を押し、表示されたURLをコピーします
   （`https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv` のような形）
5. 公開対象を **`料金表`** に切り替え、同様にコピーします
6. `assets/config.js` に貼ります。**書いた場合はこちらが優先されます**

```js
  noticesCsvUrl: 'https://docs.google.com/spreadsheets/d/e/2PACX-XXXX/pub?gid=0&single=true&output=csv',
  pricesCsvUrl:  'https://docs.google.com/spreadsheets/d/e/2PACX-XXXX/pub?gid=1234567&single=true&output=csv',
```

- **利点**：Googleが正式に用意している方法なので、仕様変更に強いです
- **注意**：反映まで最大5分ほどかかります

### 3. 読み込みの順番と安全装置

上から順に試し、読めたところで止まります。**どこかが失敗してもサイトは壊れません。**

```
① スプレッドシート（方法1または方法2）
      ↓ 読めなければ
② data/notices.csv・data/prices.csv（リポジトリの中）
      ↓ 読めなければ
③ assets/fallback-data.js（HTMLに同梱された予備）
```

次のときは「読めなかった」と判断して、②に切り替わります。

- シートが空、または通信に失敗した
- 共有設定が戻っていてHTMLが返ってきた
- **1行目の見出しが足りない**（`config.js` の `noticesRequired` `pricesRequired` で指定）

3つ目が効くので、うっかり「カテゴリ」や「料金」の見出しを消してしまっても、
料金が空欄で表示されることはありません。

> **反映のタイミング**：ブラウザにも一時的な保存が効くため、
> すぐ確認したいときは `Ctrl + F5`（スーパーリロード）をお試しください。

> ⚠ **公開したシートは、URLを知っていれば誰でも中身を読めます。**
> 原価・仕入先・個人情報などは、このスプレッドシートに置かないでください。

## シートの書き方

### お知らせシート

| 日付 | カテゴリ | タイトル | 本文 | 公開 |
|---|---|---|---|---|
| 2026-08-01 | お知らせ | ホームページを公開しました | 本文テキスト… | TRUE |

- **日付**：`2026-08-01` 形式で入力してください（新しい順に自動で並び替えます）。
- **カテゴリ**：`お知らせ` `重要` `キャンペーン` `休業` でラベルの色が変わります。それ以外は紺色になります。
- **本文**：空欄でもかまいません（タイトルだけの表示になります）。
- **公開**：`FALSE` にすると非表示になります。空欄は公開扱いです。
- **表示件数**：トップページは最新3件、`news.html` は全件です。
  トップの件数は `index.html` の `<div class="notice" id="noticeList" data-limit="3">` の数字で変更できます。

### 料金表シート

| カテゴリ | 対象 | メニュー | 料金 | 料金2 | 備考 | 公開 |
|---|---|---|---|---|---|---|
| エアコンクリーニング | 家庭用エアコン | ノーマルエアコン | 9000 | 8000 | | TRUE |
| ハウスクリーニング | 水まわり | 浴室 | 8900 | | | TRUE |

- **カテゴリ**：表のブロック単位。シートに書いた順番で上から表示されます。
- **対象**：表の左端の見出し。同じ値が続く行は自動でまとめて（結合して）表示されます。
- **料金**／**料金2**：数字だけ入れると `9,000円` の形に自動整形します。
  `都度お見積り` のような文字を入れた場合はそのまま表示されます。
- **料金2** がそのカテゴリで全部空欄なら、2列目は自動的に非表示になります。
- **備考**：メニュー名の下に小さく表示されます。
- **公開**：`FALSE` で非表示。

#### 「9,000円〜」の目安表示について

トップページの料金カードと、トップ／サービスページの「◯◯円〜」は、
**料金表シートの最安値から自動計算**しています。手で書き換える必要はありません。

ただし抗菌コートなど「単体では基本料金にならない行」は除外する必要があるため、
`assets/config.js` に除外する **対象** 名を並べています。

```js
summaryExcludeGroups: ['オプション'],
```

#### 列見出しと補足文の変更

「1台目 / 2台目以降」といった列見出しや、カテゴリごとの補足文は `assets/config.js` の
`priceMeta` で設定しています。新しいカテゴリを追加した場合は、ここにも追記してください。

```js
priceMeta: {
  'エアコンクリーニング': { col1: '1台目', col2: '2台目以降', note: '…' },
  '新しいカテゴリ名':      { col1: '料金',   col2: '',         note: '…' }
}
```

## ページ内テキストの変更

### 文言はすべて assets/i18n.js にあります

HTMLの `data-i18n="キー名"` と、`assets/i18n.js` のキーが対応しています。
**画面に出る文字を直したいときは、HTMLではなく `i18n.js` を編集してください。**
1か所直せば、日本語・英語それぞれ全ページに反映されます。

```js
'nav.service':  { ja: 'サービス一覧', en: 'All services' },
```

HTMLに書いてある日本語は、JavaScriptが無効な環境で表示される予備の文字であり、
**検索エンジンが最初に読む文字**でもあります。`i18n.js` を直したあとは、次のコマンドで
HTML側にも反映してください。

```bash
node tools/sync-text.js
```

`data-i18n` の中身、`alt` / `aria-label` / `title` 属性、そして各ページの
`<title>` と `description`・OGP（`<body data-title=" " data-desc=" ">` で指定しているもの）を、
まとめて `i18n.js` の内容にそろえます。


### ヘッダー・フッターの直し方（重要）

ビルドツールを使わない構成のため、**ヘッダー・ドロワーメニュー・フッターは14のHTMLすべてに同じ内容が書かれています**。
ページ数が増えて手作業では現実的でなくなったため、まとめて書き込むスクリプトを用意しました。

```bash
node tools/sync-parts.js
```

メニューの中身は **`tools/sync-parts.js` の先頭にある `NAV` と `SUBNAV`** が「正」です。
ここを直して上のコマンドを実行すると、14ページのヘッダー・ドロワー・フッターがすべて書き換わります
（現在地の `aria-current="page"` も自動で付きます）。

- `NAV` … ヘッダーに出るメニュー。`children` を書くとドロップダウンの子メニューになります。
- `SUBNAV` … ヘッダーには出さず、ドロワーとフッターにだけ出すページ。
- `TEL` / `TEL_LINK` … ヘッダーとドロワーの電話番号。

> Node.js が入っていない環境では実行できません。その場合は、14ファイルの
> `<!-- ============ ヘッダー（全ページ共通） ============ -->` から `</header>` までを
> 手作業でコピーしてください（ドロワー・フッターも同様）。

なお、書き換えたあとは点検スクリプトを流しておくと安心です。

```bash
node tools/check.js
```

リンク切れ（存在しないファイル・ページ内リンク先）と、
`data-i18n` で指定しているのに `assets/i18n.js` に無い文言キーを洗い出します。

### 電話番号を変える場合

エディタの「フォルダ内一括置換」で以下の2つを置き換えるのが確実です。

| 置換前 | 出現数 | 用途 |
|---|---|---|
| `06-7632-5062` | 60か所 | 画面に表示される番号 |
| `tel:0676325062` | 74か所 | タップで発信するリンク（ハイフンなし） |

> ヘッダーとドロワーの番号は `tools/sync-parts.js` の `TEL` / `TEL_LINK` にも書いてあります。
> 一括置換したあとは念のため `node tools/sync-parts.js` を実行してください。

### 住所を変える場合

住所は次の4か所に入っています。**`〒572-0050 大阪府寝屋川市黒原城内町11-10 ラ・エアナ15号`** を一括置換してください。

| 場所 | 内容 |
|---|---|
| `assets/i18n.js` | `drawer.addr` `footer.addr` `comp.addrV`（英語の `en:` も忘れずに） |
| `assets/config.js` | `company.zip` `company.address` |
| `tools/sync-parts.js` | ドロワーとフッターに書き込む初期表示用の文字列 |
| `company.html` | アクセスの節（地図のURLと住所） |

置換したあと `node tools/sync-parts.js` を実行すると、14ページに反映されます。

`assets/config.js` の `company` は、今後お問い合わせフォーム等を追加する際の参照用に用意しています。

## 公開（アップロード）方法

`ichihara-hp` フォルダの中身をそのままサーバーのドキュメントルートに置くだけです。

- **レンタルサーバー**：FTPで14のHTMLと `assets/` `data/` をアップロード
- **Cloudflare Pages / Netlify**：フォルダをドラッグ＆ドロップでデプロイ
- **GitHub Pages**：リポジトリにpushして Pages を有効化

> ローカルで確認するときは、`index.html` をダブルクリックしてもCSSやCSVが
> 読み込めない場合があります（ブラウザのセキュリティ制限）。
> その場合は簡易サーバー経由か、実際にアップロードしてご確認ください。

## 掲載内容について（要確認事項）

エクセル「㏋作成内容.xlsx」の記載をもとに作成していますが、以下は公開前にご確認ください。

1. **「保証」の記載**
   原文は「製造年数9、10年のエアコンについては、作業中に発生した破損については保障」でした。
   サイトでは「作業中に発生した破損については当社が保証いたします」と表現しています。
   対象範囲に条件がある場合は、`service.html`（対応できる症状・メーカー）と
   `company.html`（保証・アフターサービス）、`faq.html` の該当箇所を修正してください。
2. **キャンセル料・出張料**
   キャンセル料3,300円／出張料5,500円はエクセル上「今後検討」とありました。確定額をご確認ください。
   掲載箇所は `price.html`（料金に関するご注意）と `faq.html` です。
3. **シャープ製「エアリスト」**
   原文表記のまま掲載しています。正式な製品名をご確認ください。
4. **洗濯機の写真について**
   ドラム式洗濯機を分解している写真を「施工の様子」と「その他の簡易作業」に使用しています。
   洗濯機の分解洗浄を正式なメニューにする場合は、料金表シートへの追加をおすすめします
   （現在は料金表に項目がないため、写真だけが先行している状態です）。
5. **OGP画像（SNSでシェアしたときの画像）**
   `og:image` を `assets/img/osaka-aircon-cleaning-ichihara-kensetsu-ogp.jpg`（1200×630）に設定していますが、
   相対パスのままだと一部のSNSで表示されません。独自ドメインが決まったら
   `https://例.com/assets/img/osaka-aircon-cleaning-ichihara-kensetsu-ogp.jpg` のような絶対URLに書き換えてください（14ファイル）。

## アニメーションについて

`assets/style.css` の末尾「マイクロアニメーション」ブロックにまとめてあります。
**常時動き続ける装飾は入れていません**（クリーニング業という業種柄、落ち着きを優先しています）。
すべて「ホバー」「開閉」「初回表示」がきっかけの一発モーションです。

| 場所 | 動き |
|---|---|
| 電話ボタン（CTA・スマホ固定バー） | ホバーで受話器アイコンが減衰しながら鳴る |
| 「一覧を見る」等のボタン | 紺色の塗りが左から満ち、矢印が右へ動く |
| グローバルナビ | ホバーで下線が伸びる／現在地は出しっぱなし |
| サービスカード | アイコンが少し傾いて拡大、矢印が右へ |
| 料金カード | 金額が少し持ち上がる |
| FAQ | 開いたときだけ本文が上から降りてくる |
| 料金表 | 行にカーソルを合わせると背景がハイライト |
| ヒーロー・下層ページ見出し | 読み込み時に順番にふわっと表示 |
| カード・流れの各項目 | スクロールで現れる際に60〜70msずつずらして順送り |
| スマホ固定の電話バー | 画面下からせり上がって定位置に |

不要な動きは、該当ブロックをコメントアウトすれば止まります。

`prefers-reduced-motion`（OSの「視差効果を減らす」設定）が有効な環境では、
すべてのアニメーションが自動的に無効になります。

## 言語切替（日本語／英語）について

ヘッダー右上とドロワーメニュー内の「日本語 / EN」ボタンで切り替わります。

- 選んだ言語は**ブラウザに記憶され**、他のページへ移動しても維持されます。
- `https://例.com/index.html?lang=en` のようにURLを付ければ、
  **最初から英語で開くリンク**を作れます（そのまま他ページに移動しても英語のままです）。
- 初回訪問時は、ブラウザの言語設定が日本語以外なら自動的に英語で表示されます。
- 切り替えるとページタイトル・meta description・`<html lang>` も英語に変わります。

### 文言の直し方

`assets/i18n.js` の該当キーの `ja:` または `en:` を編集してください。

### スプレッドシート側の英語

お知らせ・料金表の英語は、シートに **`_en` を付けた列**を足すだけで反映されます。
空欄のままなら日本語がそのまま表示されるので、必要なところだけ埋めれば大丈夫です。

**お知らせシート**

| 日付 | カテゴリ | カテゴリ_en | タイトル | タイトル_en | 本文 | 本文_en | 公開 |
|---|---|---|---|---|---|---|---|

**料金表シート**

| カテゴリ | カテゴリ_en | 対象 | 対象_en | メニュー | メニュー_en | 料金 | 料金_en | 料金2 | 備考 | 備考_en | 公開 |
|---|---|---|---|---|---|---|---|---|---|---|---|

- **料金**は数字だけ入れておけば、日本語では `9,000円`、英語では `¥9,000` に自動整形されます。
  `料金_en` は「都度お見積り」のような**文字を入れたときだけ**必要です。
- **カテゴリ／対象**の日本語は、色分けや `config.js` の設定キーとして使われます。
  英語表示に切り替えても内部では日本語で判定しているので、**日本語の列は消さないでください**。
- 「1台目 / 2台目以降」などの列見出しは `assets/config.js` の `priceMeta`（`col1_en` / `col2_en` / `note_en`）で設定します。

- **ヘッダーは常に2段構成**です。1段目にロゴ・言語切替・電話番号、2段目にグローバルナビが入ります。

## ⚠ 全体公開の前に必ず外すもの（noindex）

レビュー中は検索エンジンに登録されないよう、14ページすべてに次の1行が入っています。

```html
<meta name="robots" content="noindex, nofollow">
```

**このタグが入っている間は、Google検索に一切表示されません。**
内容が確定して一般公開する段階になったら、14ファイルからこの行（と直前のコメント行）を削除してください。

対象ファイル：`index.html` `aircon.html` `house.html` `vacancy.html` `area.html` `works.html`
`faq.html` `business.html` `other.html` `recruit.html` `company.html`
`service.html` `price.html` `news.html`

> **`robots.txt` で `Disallow: /` を書く方法は使わないでください。**
> クロール自体がブロックされて `noindex` を読んでもらえず、かえってURLだけが
> 検索結果に残ってしまうことがあります。上記のmetaタグだけが正しいやり方です。

外し忘れを防ぐため、公開作業のチェックリストに入れておくことをおすすめします。

1. **14ファイルから `noindex` を削除**（下のコマンドが使えます）
2. `node tools/build-sitemap.js` を実行して `sitemap.xml` の日付を更新
3. Google Search Console で **サイトマップを送信**（`sitemap.xml` と入力）
4. Search Console で主要ページの **インデックス登録をリクエスト**

OGP画像・canonical・構造化データの絶対URLは、すでに設定済みです
（`assets/config.js` の `site.url` が元になっています）。

`noindex` をまとめて外すコマンド（Git Bash / macOS のターミナル）：

```bash
sed -i '/レビュー中：検索エンジンに登録させない設定/d; /content="noindex, nofollow"/d' *.html
```

## ヒーローの高さについて

**電話ボタンまでが1画面に収まる**よう、文字サイズを「画面の横幅」だけでなく
**「画面の高さ」にも連動**させています（`min(◯vw, ◯vh)` という書き方）。

```css
.hero__headline{font-size:clamp(36px,min(5.7vw,8.4vh),74px)}
.hero__price-num{font-size:clamp(48px,min(7.8vw,11.6vh),104px)}
```

画面の縦が短いノートPCでも文字が自動的に小さくなり、はみ出しません。
もっと大きく見せたい場合は `8.4vh` `11.6vh` の数値を上げてください
（上げすぎると縦の短い画面で電話ボタンが画面外に出ます）。

## 下層ページの見出し帯について

サービス内容・料金表・お知らせ・よくあるご質問・会社概要の各ページ上部の帯には、
**トップと同じヒーロー写真**を敷いています（`assets/style.css` の `.page-hero`）。

```css
.page-hero{
  background:
    linear-gradient(150deg,rgba(11,61,114,.92) 0%,rgba(14,74,128,.90) 55%,rgba(19,106,152,.88) 100%),
    url("img/osaka-aircon-cleaning-ichihara-kensetsu.webp") center 42% / cover no-repeat;
}
```

**紺色の覆いの濃さ（`.92` `.90` `.88` の数字）は、白い文字が読める限界に合わせています。**
写真が明るい室内なので、これ以上薄くすると文字とのコントラストが基準（4.5:1）を下回ります。

現在の実測値：最悪 4.75:1（PC）／4.66:1（スマホ）、平均 6.57:1。

写真をもっとはっきり見せたい場合は、文字色を濃色に変える等の設計変更が必要です。

公開URLは **`assets/config.js` の `site.url`** が「正」です（現在 `https://ichihara-hp.pages.dev/`）。
ここを直して `node tools/sync-text.js` と `node tools/build-sitemap.js` を実行すると、

| 場所 | 内容 |
|---|---|
| `<link rel="canonical">` | そのページの正式なURL。`/` と `/index.html` のような重複を防ぎます |
| `<meta property="og:url">` | SNSでシェアされたときのURL |

#### URLに `.html` が付かない理由

Cloudflare Pages は `/aircon.html` へのアクセスを **`/aircon` へ転送します**（308リダイレクト）。

```
https://ichihara-hp.pages.dev/aircon.html  →  308  →  /aircon
```

そのため、canonical・og:url・サイトマップには **`.html` を付けないURL** を載せています。
ここでリダイレクトの前のURLを載せると、サーチコンソールで
「ページにリダイレクトがあります」と表示され、登録されません。

ページ同士のリンク（`href="aircon.html"`）は `.html` 付きのままです。
どのサーバーでも動く書き方で、Cloudflare側が転送してくれるためです。

`.html` をそのまま配信するサーバーへ引っ越すときは、
`assets/config.js` の `site.stripHtmlExtension` を `false` にして、
`node tools/sync-text.js` と `node tools/build-sitemap.js` を実行してください。

## sitemap.xml と robots.txt

どちらも `tools/build-sitemap.js` が作ります。**手で書き換えないでください。**

```bash
node tools/build-sitemap.js
```

- フォルダ直下の `.html` を自動で拾うので、**ページを増やしたらこれを流すだけ**です。
- 各ページの最終更新日は、gitの記録から自動で入ります。
- 公開URLは `assets/config.js` の `site.url` を見ています。

### sitemap.xml

全14ページのURLと最終更新日の一覧です。Googleはリンクをたどってもページを見つけますが、
サイトマップを出しておくと **「送った14ページのうち何ページ登録されたか」** が
サーチコンソールで確認できます。登録されなかったページの理由も表示されます。

### robots.txt

```
User-agent: *
Allow: /

Sitemap: https://ichihara-hp.pages.dev/sitemap.xml
```

## Googleサーチコンソールの所有者確認

サイトのデータを見るには、Googleに「このサイトの持ち主である」ことを示す必要があります。

### 手順

1. [Google Search Console](https://search.google.com/search-console) を開き、Googleアカウントでログイン
2. プロパティの追加で **「URLプレフィックス」** を選び、`https://ichihara-hp.pages.dev/` を入力
3. 確認方法が並ぶので、下の **A**（設置済み）か **B** を選びます

> **「ドメイン」プロパティは選べません。** DNSを触る必要があり、`.pages.dev` の
> ドメインはCloudflareのものだからです。必ず「URLプレフィックス」を選んでください。

### A. HTMLファイル方式 ← ✅ この方式で設置済み

リポジトリ直下に **`google042ace2de9b7076f.html`** を置いてあります。

```
https://ichihara-hp.pages.dev/google042ace2de9b7076f.html
```

> ### ⚠ このファイルは絶対に消さないでください
> 消すと所有者確認が取り消され、サーチコンソールのデータが見られなくなります。
> `tools/` のコマンド（`sync-parts.js` など）は `tools/pages.js` を通して
> 「サイトのページ」だけを対象にしているため、このファイルには一切触れません。
> 手作業で整理するときだけご注意ください。

別のGoogleアカウントで登録し直す場合は、新しい確認ファイルを同じ場所に置いてください
（古いファイルは残したままで問題ありません）。

### B. HTMLタグ方式

Googleが表示する

```html
<meta name="google-site-verification" content="ランダムな文字列">
```

の **`content` の中身だけ** を、`assets/config.js` に貼り付けます。

```js
site: {
  url: 'https://ichihara-hp.pages.dev/',
  googleSiteVerification: 'ここに貼り付け'
}
```

そのあと次を実行すると、トップページの `<head>` に自動で入ります。

```bash
node tools/sync-text.js
```

空文字に戻して実行すれば、タグは自動で消えます。

### 確認後の注意

- **置いたファイル（またはタグ）は消さないでください。** 消すと確認が取り消されます。
- サーチコンソールの登録は**ドメインごと**です。将来 独自ドメインに移る場合は、
  **別サイトとして登録し直し**になります。
- `noindex` が入っているうちは、サイトマップを送っても
  「送信されたURLに noindex タグが追加されています」というエラーになります。
  **サイトマップの送信は全体公開のあとに**行ってください（所有者確認だけ先に済ませるのはOKです）。
